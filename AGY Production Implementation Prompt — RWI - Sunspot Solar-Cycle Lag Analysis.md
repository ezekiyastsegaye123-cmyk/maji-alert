# 8. 11-Year Schwabe-Cycle Smoothing

Apply an **11-year centered moving average** to both RWI and Sunspot Number.

The required mathematical definition is:

\[
x_{smoothed}(t)=
\frac{1}{11}\sum_{k=-5}^{5}x(t+k)
\]

Use a true centered 11-year window.

Conceptually:

```python
rolling(window=11, center=True)
```

The implementation must not use a trailing 11-year average.

## Important boundary behavior

For the first and last five years, a complete 11-year centered window does not exist.

Do **not** silently use partial windows if the purpose is explicitly to isolate the Schwabe cycle using the stated 11-year formula.

Use a complete 11-observation window and document that the first/last five observations cannot receive a valid smoothed value.

Ensure the input is sorted chronologically before rolling.
